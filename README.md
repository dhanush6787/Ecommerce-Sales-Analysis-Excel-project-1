# E-commerce Sales Analysis (Excel Project)

This project analyses e-commerce sales data using Excel. I cleaned the data, made pivot tables and charts, and built a dashboard with slicers.

## Files

- Excel work.xlsx : final Excel file with pivot tables, charts and dashboard
- Ecommerce_Sales_Raw Dataset_updated .xlsx : raw dataset
- Ecommerce_Sales_Analysis_Report.pdf : report with screenshots and insights

## What I Did

1. Cleaned the data using Find and Replace, PROPER, TRIM, IF and MEDIAN
2. Connected the sheets using the Data Model and XLOOKUP
3. Made pivot tables and charts for descriptive, diagnostic, predictive and prescriptive analysis
4. Built a dashboard with slicers

## Tools Used

Excel, Pivot Tables, Slicers, Power Pivot, XLOOKUP

## Main Findings

- Total sales is about Rs. 21.74 lakh from 2000 orders
- Sports and Electronics earn the most
- West region has the lowest sales
- Online stores sell the most
